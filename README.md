# 理財記錄本

單檔網頁程式，用於管理個人購買的理財產品（定存、結構型商品、理財專案等）。
不需安裝、不需伺服器，用瀏覽器開啟 `index.html` 即可使用；資料存放在瀏覽器 localStorage，重啟不遺失。

## 功能

1. **記錄管理** — 新增、編輯、刪除、列表瀏覽；填寫購買日與存期會自動帶出到期日（月底與閏年已正確處理）。
2. **篩選與排序** — 銀行／機構、幣種、到期日區間、利率區間（重疊／完全包含）、關鍵字搜尋；點欄位標題即可排序。
3. **統計分析**
   - 依幣種彙總：筆數、本金、佔比、預期收益區間、加權利率
   - 依銀行／機構彙總：筆數、本金、佔比、加權利率區間
   - 預期收益區間：單利估算 `本金 × 利率 × 存續天數 ÷ 365`
   - 到期提醒：已到期與 N 天內到期（預設 30 天，可自訂）
4. **資料持久化與備份** — localStorage 自動儲存；可匯出 JSON 備份、匯入（合併／覆蓋）、匯出 CSV（含 BOM，Excel 不亂碼）。
5. **格式與驗證** — 金額千分位兩位小數並帶幣種符號，利率統一 `x.xx%`；必填、日期有效性、到期日不早於購買日、本金 > 0、利率 0–100 且下限 ≤ 上限，皆即時提示並阻止儲存。

## 資料欄位

| 欄位 | 說明 |
| --- | --- |
| 銀行／機構 | 必填 |
| 產品編號 | 選填 |
| 產品名稱 | 必填 |
| 購買日 | 必填，日期 |
| 存期 | 數值 + 單位（日／個月／年） |
| 到期日 | 由購買日 + 存期自動帶出，可手動覆寫 |
| 幣種 | 必填，如 TWD、USD、CNY、HKD、MOP、JPY |
| 本金金額 | 必填，需 > 0 |
| 利率下限 / 上限 | 年利率 %，上限需 ≥ 下限 |
| 備註 | 選填 |

## 匯率

- 每次開啟會自動聯網更新匯率，依序嘗試三個免金鑰來源（jsDelivr currency-api → currency-api.pages.dev → open.er-api），任一成功即停止。
- 抓取以「基準幣種」為準（預設 TWD，可切換 TWD／USD／CNY／HKD／MOP／EUR／JPY）。
- 網路不可用時沿用上次成功取得的匯率或內建預設值，只顯示提示，不影響其他功能。
- 匯率僅用於跨幣種佔比折算，不改動原始記錄；手動修改過的值會在下次更新時被覆蓋。

## 使用方式

直接用瀏覽器開啟 `index.html`。首次開啟為空白，可點「載入範例資料試用」查看效果（7 筆、多幣種），之後可刪除。

資料儲存在該瀏覽器的 localStorage，若更換瀏覽器或清除網站資料，請先用「匯出備份 (JSON)」保存。
